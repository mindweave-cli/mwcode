Fixing the refresh race

Two callers near expiry both saw a stale token and both fired refresh() — the second call overwrote the first with a token for a slightly earlier window, which is what was logging people out mid-session.

What changed:

Shared in-flight guard — concurrent callers now await the same promise instead of each firing their own request.
Guard clears on settle — the next expiry starts a fresh refresh rather than reusing a resolved one.
